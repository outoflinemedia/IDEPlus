# IDEPlus

A code editor for macOS that edits files straight on your FTP server. Open a file from your site, change it, and every save uploads it back.

## What it does

- **Edit on your server.** Connect to FTP or FTPS sites, browse their folders, and open any file. Each save uploads it, with a clear ✓ when it's done, or ⚠︎ and Try Again when it isn't.
- **Save new files to the server.** Save to FTP shows exactly which server and folder a file goes to, waits for your OK, and asks before replacing a file that's already there.
- **Favorites.** Keep the files you're working on together in projects, even across different sites, and open them with a double-click.
- **A modern code editor.** Tabs, line numbers, syntax colours for PHP, HTML, CSS, JavaScript, TypeScript, SQL, Python and more, smart brackets and quotes, autocomplete, ready-made code clips, and find and replace.
- **Picks up where you left off.** The tabs you had open come back when you reopen the app.
- **Private by design.** Your sites stay on your Mac, and passwords are kept by macOS in your Keychain, not by IDEPlus. Nothing is sent anywhere except to your own FTP server.

## Requirements

macOS 13 or later.
